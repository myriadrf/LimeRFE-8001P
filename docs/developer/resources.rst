Resources
#########

Please refer to the following projects for the PCB design and manufacturing files and host software for LimeRFE 8001P:

* `Hardware Design`_ (KiCad project, schematics, Gerbers and BOM)
* `LimeRFE 8001P control software`_ (standalone GUI for control of the board over USB)
* `LMS8001 documentation`_ (datasheet and application notes for the LMS8001 frequency shifter)

.. _Hardware Design: https://github.com/myriadrf/LimeRFE-8001P
.. _LimeRFE 8001P control software: https://github.com/myriadrf/LimeRFE-8001P_CTL
.. _LMS8001 documentation: https://github.com/myriadrf/LMS8001-docs
