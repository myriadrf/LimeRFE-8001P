Board Versions
##############

LimeRFE 8001P v1.0 and v1.1 boards are supported by the same software. New hardware features added in each board version are listed in Table 1. For a detailed list of changes between the board versions, see :doc:`/reference/changelog`.

.. list-table:: Table 1. New features in each board version
   :header-rows: 1

   * - Version
     - New features
   * - v1.1
     - Digital step attenuators in the TX paths (TX1 Att. and TX2 Att.), 0 – 31.75 dB in steps of 0.25 dB.

       IF band-pass filters at the IFTX inputs and IFORX outputs.

       I2C connector (J1) for front panel control.

       USB pin header (J29) for connection to a motherboard.

       12 V DC barrel connector (J30).
   * - v1.0
     - Initial version.
